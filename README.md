# TerraGuard GIS

An intelligent geoinformation system for monitoring, preserving, and restoring the fertile soil layer during construction.

## Project goal

Support soil protection throughout construction by combining geospatial data, soil condition monitoring, and restoration planning.

## Planned capabilities

- Map construction sites and areas with fertile topsoil.
- Track soil conditions and construction impacts.
- Support planning for topsoil removal, storage, and reuse.
- Monitor soil restoration and reclamation progress.

## Status

Diploma project in the planning stage. Implementation and setup instructions will be added as development progresses.
